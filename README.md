Token Radar ranks pre-token protocols by an implied value calibrated from the snapshot's own tokenized comparables, and gives each one a concrete farm plan with costs and times. The board covers the whole 40-protocol watchlist plus the 160 pre-token protocols below the floor with the most TVL; the live-token protocols are shown apart, with the market's own values.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/token-radar-01-kit/input/snapshot.json
```
